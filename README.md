# NutriFlow

NutriFlow es una aplicación móvil de nutrición y seguimiento de hábitos alimenticios, reconstruida a partir de un proyecto académico de UNAPEC y evolucionada con una arquitectura profesional orientada a producto.

## Visión

La nueva versión de NutriFlow tendrá una aplicación móvil moderna para registrar alimentos, controlar calorías y macronutrientes, gestionar objetivos nutricionales, alergias y preferencias, escanear productos y visualizar el progreso del usuario.

## Stack objetivo

- React Native + Expo + TypeScript
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Docker Compose
- GitHub Actions
